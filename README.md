# FrenchColors

Одностраничный тренажёр для изучения французских названий цветов.

## Live

- GitHub Pages: <https://polpal1623.github.io/FrenchColors/>
- Репозиторий: <https://github.com/PolPal1623/FrenchColors>

## Что внутри

- 10 цветов в словаре и 10 раундов за одну тренировку.
- Два формата практики: ввод слова и выбор подходящего цвета.
- IPA и русская подсказка произношения после ответа.
- Адаптивный интерфейс и ручное переключение темы.
- Итоговый экран с историей всех ответов.

## Запуск

1. Откройте `index.html` в современном браузере.
2. Никакой сборки и внешних библиотек не требуется.

## Редактирование

- Основные данные лежат в массиве `COLORS`.
- Количество раундов автоматически синхронизировано с размером словаря.
- Дизайн приведён к единому стилю French Learning Suite.
